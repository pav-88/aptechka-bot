# 🏥 Аптечка — Telegram Bot

Telegram бот для управления домашней аптечкой. Помогает следить за сроками годности, остатками лекарств, обрабатывает назначения врача и ищет аналоги.

## Возможности

### 📦 Управление аптечкой
- **Добавление лекарств** — через фото или текст (название, срок годности, количество)
- **Моя аптечка** — полный список всех лекарств с сортировкой по сроку годности
- **Контроль остатков** — автоматическое уведомление, если осталось ≤3 шт.

### ⏰ Напоминания
- Ежедневная проверка сроков годности в 9:00
- Уведомления об истекающих сроках (за 3 дня)
- Уведомления о низком остатке
- Возможность отключить напоминания для конкретного лекарства

### 👨‍👩‍👧‍👧 Семейный профиль
- До 10 членов семьи
- Учёт возраста и пола
- Назначения врача привязываются к конкретному члену семьи

### 🩺 Назначения врача
- Отправьте фото или текст назначения
- Бот сверяет список с вашей аптечкой
- Показывает, чего не хватает
- Ищет возможные аналоги по действующему веществу

### 💊 Справочник лекарств
- Поиск по названию
- Информация о дозировке и действующем веществе

### 🏥 Первая помощь
- Категоризированный поиск по симптомам
- Быстрый доступ: что есть от температуры, боли, аллергии и т.д.

### 📊 Отчёты
- Полная сводка по аптечке
- Просроченные лекарства
- Истекающие в ближайшие 3 месяца
- Лекарства с низким остатком

## Установка и запуск

### Требования
- Node.js 20+
- npm

### 1. Клонировать репозиторий
```bash
git clone <repo-url>
cd aptechka-bot
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Настроить окружение
Скопируйте `.env.example` в `.env` и укажите токен бота:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=file:./dev.db
```

### 4. Создать базу данных
```bash
npx prisma migrate dev
```

### 5. Запустить
```bash
npm run dev
```

## Структура проекта

```
src/
├── bot/              # Основной бот и стартовый хендлер
├── features/
│   ├── analytics/    # Отчёты и аналитика
│   ├── family/       # Семейные профили
│   ├── firstaid/     # Первая помощь
│   ├── medicines/    # Справочник лекарств
│   ├── mykit/        # Моя аптечка
│   ├── photo/        # Распознавание по фото (в разработке)
│   ├── prescriptions/# Назначения врача
│   ├── reminders/    # Напоминания
│   └── symptoms/     # Симптомы -> лекарства
├── shared/           # Общие утилиты и БД
└── config/           # Конфигурация
```

## Технологии

- **Runtime:** Node.js 20+
- **Язык:** TypeScript (strict mode)
- **Бот:** grammY
- **База данных:** SQLite через Prisma ORM
- **Планировщик:** node-cron
- **Распознавание:** Tesseract.js (в разработке)
