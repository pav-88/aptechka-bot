# 🏥 Аптечка — Telegram Bot

Telegram бот для управления домашней аптечкой. Помогает следить за сроками годности, остатками лекарств, обрабатывает назначения врача через DeepSeek AI, ищет аналоги и проверяет совместимость.

## Возможности

### 📦 Управление аптечкой
- **Добавление лекарств** — через фото (DeepSeek Vision) или текст (название, срок годности, количество)
- **Моя аптечка** — полный список всех лекарств с пагинацией, сортировкой по сроку годности
- **Контроль остатков** — автоматическое уведомление, если осталось ≤3 шт.

### ⏰ Напоминания
- Ежедневная проверка сроков годности в 9:00 (cron)
- Уведомления об истекающих сроках (за 3 дня)
- Уведомления о низком остатке
- Возможность отключить напоминания inline-кнопками

### 👨‍👩‍👧‍👧 Семейный профиль
- До 10 членов семьи на пользователя
- Учёт возраста и пола
- Приглашение через код `APT-XXXX-XXXX` (действует 7 дней)
- Привязка Telegram-аккаунтов — вся семья получает уведомления
- Синхронизация профилей между связанными аккаунтами

### 🩺 Назначения врача
- Отправьте фото или текст назначения
- DeepSeek распознаёт диагноз и список лекарств
- Бот сверяет с вашей аптечкой — показывает, чего не хватает
- Ищет аналоги по действующему веществу (БД → DeepSeek fallback)
- Проверяет совместимость лекарств

### 💊 Справочник лекарств
- Поиск по названию с пагинацией
- Информация о дозировке и действующем веществе

### 🏥 Первая помощь
- Категоризированный поиск по симптомам (температура, боль, аллергия, простуда, желудок, раны)
- Быстрый доступ к тому, что есть в аптечке

### 📊 Отчёты
- Полная сводка по аптечке
- Просроченные лекарства
- Истекающие в ближайшие 3 месяца
- Лекарства с низким остатком
- Лекарства без указания срока

## Установка и запуск

### Требования
- Node.js 20+
- npm

### 1. Клонировать репозиторий
```bash
git clone <repo-url>
cd aptechka-bot
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Настроить окружение
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=file:./dev.db
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

> `DEEPSEEK_API_KEY` необходим для распознавания фото и поиска аналогов. Получить: https://platform.deepseek.com

### 4. Создать базу данных и применить миграции
```bash
npx prisma migrate dev
```

### 5. Запустить
```bash
npm run dev
```

### Docker
```bash
docker build -t aptechka-bot .
docker run -e BOT_TOKEN=your_token -e DEEPSEEK_API_KEY=your_key aptechka-bot
```

## Структура проекта

```
src/
├── bot/               # Основной бот: инициализация, middleware, старт
├── features/
│   ├── family/        # Семейные профили + приглашения
│   ├── firstaid/      # Первая помощь по категориям
│   ├── medicines/     # Справочник лекарств (с пагинацией)
│   ├── mykit/         # Моя аптечка (с пагинацией)
│   ├── photo/         # Распознавание по фото (DeepSeek Vision)
│   │   └── add-medicine-handler.ts  # Подтверждение добавления
│   ├── prescriptions/ # Назначения врача + совместимость
│   ├── reminders/     # Напоминания + остановка по inline-кнопкам
│   └── reports/       # Отчёты по аптечке
├── shared/            # Общие утилиты: БД, AI, rate-limit, типы
└── config/            # Конфигурация из .env
```

## Технологии

- **Runtime:** Node.js 20+
- **Язык:** TypeScript (strict mode)
- **Бот:** grammY
- **База данных:** SQLite через Prisma ORM
- **AI / Vision:** DeepSeek API (OpenAI-совместимый клиент)
- **Планировщик:** node-cron
- **Rate limiter:** in-memory (20 запр/мин на пользователя)
- **Деплой:** Railway.app / Docker (multi-stage)
